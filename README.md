# GrowUp

Android personal-finance MVP built with Kotlin and Jetpack Compose.

The first version supports a local finance dashboard, adding asset or liability accounts, recording income and spending, setting a savings target, and showing explainable daily suggestions. It deliberately keeps bank connections read-only and represented by an interface boundary; no credentials or money-moving actions are handled by the app.

Open the project in Android Studio (JDK 17, Android SDK 35) and run the `app` configuration. The UI starts with realistic sample data so the core flow is visible immediately.

See [docs](docs/) for the product, architecture, design, and test plan.
